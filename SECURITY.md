# Security policy

This policy covers every repository in the CodeClarityCE organization.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security problem.

Report it privately through GitHub instead: open the affected repository, go to the **Security** tab and choose **Report a vulnerability**. If you are not sure which repository is affected, report it on [`CodeClarityCE/codeclarity-dev`](https://github.com/CodeClarityCE/codeclarity-dev/security/advisories/new).

Include what you can of:

- the affected repository, component and version or commit
- the steps to reproduce, or a proof of concept
- the impact you expect

## What to expect

- We acknowledge your report within 5 working days.
- We keep you updated while we work on a fix.
- We credit you in the published advisory unless you prefer otherwise.

## Supported versions

Fixes go into the latest release. Older releases do not get security updates; upgrade to the latest release to get a fix.
